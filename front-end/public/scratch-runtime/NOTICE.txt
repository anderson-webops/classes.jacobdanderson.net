Scratch classroom editor

This site serves the @scratch/scratch-gui 15.1.1 standalone distribution.
The reproducible preparation script changes only its two webpack asset bases
from / to /scratch-runtime/vendor/ for this site. The patch and adapter source
are included in the site source repository linked below.
