# Conditional flow: case inputs

## baseline

### Baseline observation

Run the supplied LASER active-level 2/60 minute/open/unsupervised/not-busy case and CNC active-level 0/20 minute/open/supervised/busy case. Predict both client strings and complete event lists first.

## judgment

### Conditional or variant?

Compare active-account denial, the ordered guest/closed/busy chain, and the three fee formulas. Identify behavior that varies by machine and behavior that expresses one ordered policy.

## decision-table

### Complete valid decision table

For LASER,60 minutes unless noted, compare: guest/closed/busy; suspended member/closed; active level 2/closed; active level 2/61 minutes; active level 1/busy; active level 2/busy; active level 2/not-busy. All are unsupervised. Then compare null audit with null machine and 0 minutes.

## core

### Preserve history and validation

Begin with audit event seed. Evaluate unsupervised STANDARD,active level 0,1 minute,open/not-busy twice. Attempt to mutate the first returned event list. Compare missing machine plus invalid minutes, and present inactive member with invalid training.

## diagnostic

### Find the smallest counterexample

Analyze inactive OR→AND, reversed supervision/training operands, duplicate final recording, and replacing a missing audit with a no-op.

## transfer

### Short-circuit transfer

Compare STANDARD active level 0/1 minute unsupervised/not-busy; CNC active level 0/20 minutes supervised/busy; CNC active level 0/46 minutes supervised/busy. All labs are open.

## extension

### Optional fee and reporter cases

Check STANDARD 30 and 31, LASER 60, CNC 15 and 16. Book approved LASER 60 with present/absent reporter; deny a guest. Try missing request with a recording reporter and existing seed history; try null audit.
