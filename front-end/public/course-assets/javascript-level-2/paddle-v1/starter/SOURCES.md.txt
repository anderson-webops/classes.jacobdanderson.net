All original HTML,CSS,JavaScript and settings were reviewed on 2026-11-14 and
retained with the official source exports. Both use Babel,no HTML/CSS preprocessor,
no CSS base/prefixer and no external resources or packages.
The starter has blank HTML/CSS and a single task comment.
The reference actually assigns a500-by-500 canvas. Its unused screenWidth 800 constant
does not describe the rendered surface.

These local teaching files are newly authored from the assignment behavior.
They preserve the black 100-by-20 paddle at (0,0),500-by-500 canvas,left/right input
and 10 units/frame. They supply the missing starter setup,clamp movement at 0 and 400,
use named keys,and clear held input on focus/visibility loss.
The original starter MIT notice is retained in LICENSE-original.txt.
The reference export contains no separate license file;its source remains in the
private audit capture and was not copied into these local files.
