The original starter's HTML and CSS are empty and its script is an assignment comment. The original reference has four recognized cases (hot, rain, snow and cold), text/image/color updates and an unknown-input fallback. These source states and all CodePen settings were captured from official ZIP exports on 2026-11-13.

The local reference retains the original conditional structure, four weather messages and panel-class changes. It adds wind to meet the five-case assignment, replaces remote product pictures with newly drawn local SVG illustrations, supplies image alternatives, clears/hides the picture for unknown input, and repairs label, input width and heading contrast. The starter's assignment script remains verbatim.

The original Pens load Materialize 1.0.0 and D3 5.16.0; the reference additionally loads Material Design Icons 3.0.1. This pack retains Materialize CSS and uses the already verified D3 7.9.0 distribution. The original click handler does not use the event argument that changed between D3 versions. A text Submit button removes the icon-font dependency. Library licenses accompany both roles.
