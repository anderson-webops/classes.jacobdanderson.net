# Coordinate and color checks

The SVG uses a logical 1000 by 1000 coordinate area. Each square is 50 by 50.
Both coordinate lists are 50, 125, 200, 275, 350, 425, 500, 575, 650, 725.
Every x/y combination appears once: 100 rectangles, 10 distinct x values and 10 distinct y values.

| column | row | x | y | width | height |
| --- | --- | --- | --- | --- | --- |
| 0 | 0 | 50 | 50 | 50 | 50 |
| 1 | 0 | 125 | 50 | 50 | 50 |
| 0 | 1 | 50 | 125 | 50 | 50 |
| 4 | 6 | 350 | 500 | 50 | 50 |
| 9 | 9 | 725 | 725 | 50 | 50 |

Each red, green and blue channel is an integer from 1 through 255.
For a controlled random value of 0, the formula produces 1; 0.5 produces 128;
a random value just below 1 produces 255. A complete color is rgb(128,128,128).
Reloading preserves geometry and normally changes colors.
The blank starter has no SVG until its missing project code is written.
