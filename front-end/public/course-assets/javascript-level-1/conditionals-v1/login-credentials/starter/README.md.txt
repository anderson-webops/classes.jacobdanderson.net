# Login Credentials

Use fictional values to set a username and password. Ask for the username until it matches, then ask for the password until it matches. Alert when both exact, case-sensitive comparisons succeed. The values remain in memory for this exercise; this is not an account or a server login.

## Checks

Choose a fictional pair, then try a wrong username, the correct username, a wrong password and the correct password. Letter case and spaces remain significant. The reference rejects blank setup values and lets Cancel end any prompt without accepting null credentials or trapping a retry loop.

## Run

Open index.html in a browser with the exported files together. The project runs offline.
