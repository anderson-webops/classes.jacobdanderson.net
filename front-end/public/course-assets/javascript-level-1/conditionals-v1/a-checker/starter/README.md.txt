# A-Checker

Prompt for a word, scan its characters with a loop and use a boolean to report whether it contains lowercase `a`. Keep the comparison case-sensitive.

## Checks

Check `banana` and `cat` (contain `a`), `kiwi` and `ARROW` (do not). The reference reports canceled, empty or whitespace-only input before scanning. Preserve spaces and letter case in any nonempty response.

## Run

Open index.html in a browser with the exported files together. The project runs offline.

Complete the exercise above the supplied printToScreen helper. Its output wraps on narrow pages.
