# Welcome Survey

Open `index.html` with every exported file in place. No server, package installation or network connection is required.

Collect first and last names, convert two number responses before adding them, log the sum, and report the last character of a nonempty food name. With `Avery`, `River`, `2`, `3` and `mango`, the page shows `Avery River`, the console reports `5`, and the alert reports `o`.

Complete exercise code above the supplied `printToScreen` helper. Its output wraps on narrow pages.

The supplied helper uses the original D3 5.16.0 library locally. Retain `vendor/d3.min.js` and `LICENSE-d3.txt`.

Juni Learning source: [starter](https://codepen.io/junilearning/pen/OJMxyqw).
