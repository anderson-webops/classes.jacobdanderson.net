# Basics of HTML & CSS

Use a fictional first and last name for these HTML and CSS exercises:

1. Put the first and last names in separate `div` elements.
2. Put two `span` elements inside one `div`, one for each name. Compare this with the separate `div` elements.
3. Put a `br` line break between another pair of name `div` elements.
4. Add an `img` using the included `landscape.svg`, with alternative text describing the image. Another suitable local image can be used instead.
5. Add an anchor (`a`) linking to `https://www.wikipedia.org/`.
6. Select `body` in CSS and set a background color.
7. Select `div` and center its text.
8. Select `span` and set its font size to 20 pixels.
9. Select `img` and set both its width and height to 200 pixels.
10. Make `div` text bold and `span` text normal. Explain which text inherits bold weight and which rule overrides it.

Open `index.html` directly in a browser without a server. Edit the markup in `index.html` and the presentation in `styles.css`, then refresh the browser.
