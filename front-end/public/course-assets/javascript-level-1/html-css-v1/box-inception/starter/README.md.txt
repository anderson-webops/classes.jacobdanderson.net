# Box Inception

Recreate four views of the same six colors, in this order: red, orange, yellow, green, blue, purple. Each colored box is 50 by 50 pixels.

- Under `Block Display`, give each box `display: block` so the six boxes form a vertical column.
- Under `Inline Block Display`, give each box `display: inline-block` so they share a line when enough space is available.
- Under `Grid`, use three ordinary block `div` rows containing two inline-block boxes each. This exercise uses HTML grouping, before the later CSS Grid module.
- Under `Table`, use a table with three rows and two cells per row, with one colored box in each cell.

The paired colors in each grid and table row are red/orange, yellow/green, and blue/purple. Compare where the browser inserts line breaks in the four structures.

Open `index.html` directly in a browser without a server. Edit the markup in `index.html` and the presentation in `styles.css`, then refresh the browser.
