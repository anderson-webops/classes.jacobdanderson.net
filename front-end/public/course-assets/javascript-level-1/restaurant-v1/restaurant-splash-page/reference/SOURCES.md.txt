Only a completed reference was captured for this supplemental project. The unfinished starter is an independently authored companion and is not presented as an original Juni starter. The reference retains the original two parallax sections, five alternating horizontal cards, dish names, descriptions, sample prices, and restaurant identity. Semantic headings, phone reflow, keyboard navigation, static no-JavaScript images, reduced motion and resize handling are authored corrections.

Historical contact details are replaced with a reserved example phone number and .example address. The menu prices and restaurant copy are fictional teaching data. The two unverified background photographs and the original unverified soup photograph are preserved as URLs in the exact original-source fixture rather than redistributed here. Backgrounds reuse two licensed original menu photographs; the soup uses a supplied SVG illustration. The remaining four photographs are original menu images. The Commons provider thumbnails are embedded byte-for-byte in local SVG companions and displayed with CSS cropping.

Materialize 1.0.0: https://cdnjs.cloudflare.com/ajax/libs/materialize/1.0.0/ (MIT, LICENSE-Materialize.txt). The captured original also declared unused jQuery 3.4.1. Unused jQuery and D3 are not required or bundled. The original edge option does not configure Parallax; the reference uses responsiveThreshold.
