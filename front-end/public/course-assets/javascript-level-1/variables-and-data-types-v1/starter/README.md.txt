# Variables and Data Types

Open `index.html` with every exported file in place. No server, package installation or network connection is required.

Uncomment the supplied walkthrough or create a string, number, boolean, null and undefined value, then pass each value to `printToScreen`. Use `let` for a binding that can be reassigned and `const` for one that cannot. `null` is a primitive value even though `typeof null` returns `"object"`; `typeof undefined` returns `"undefined"`. Compare `"1" + "1"` with `1 + 1`, and use a leading `+` to convert a numeric string. See [MDN data types](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Data_structures#primitive_values).

Complete exercise code above the supplied `printToScreen` helper. Its output wraps on narrow pages.

The supplied helper uses the original D3 5.16.0 library locally. Retain `vendor/d3.min.js` and `LICENSE-d3.txt`.
