# Debugging Math Practice

Pick a random integer from -10 through 50. Add its remainder after division by 7, raise the updated number to an entered exponent, divide by 11, then round up. Trace the result after each stage.

## Exercise

The supplied printToScreen helper displays text as text, without interpreting HTML.

## Checks

The starter deliberately contains syntax and arithmetic errors. Repair the first reported error, then check the random range, remainder operator, compound assignment, Math.pow argument order, division assignment and Math.ceil. JavaScript % keeps the dividend sign: -10 % 7 is -3.

## Run

Open index.html in a browser. The same HTML, CSS, JavaScript and local D3 files run from the exported project without a network connection. Prompts accept input in browser dialogs; results appear on the page.
