# Randomly Random Party

Choose a month from 5 through 7, a day from 1 through 30, an hour from 10 through 20, and a minute from 0 through 59. This exercise deliberately treats each month as 30 days.

## Exercise

Complete the exercise above the marked line; keep the supplied output helper.

The supplied printToScreen helper displays text as text, without interpreting HTML.

## Checks

Math.random() includes 0 and excludes 1. For an inclusive integer range, multiply by the number of possible integers, round down, and add the minimum. Check the formulas at 0 and just below 1. The commented optional challenge accepts a birth month, wraps December/January, and retains the same day and time bounds.

## Run

Open index.html in a browser. The same HTML, CSS, JavaScript and local D3 files run from the exported project without a network connection. Prompts accept input in browser dialogs; results appear on the page.
