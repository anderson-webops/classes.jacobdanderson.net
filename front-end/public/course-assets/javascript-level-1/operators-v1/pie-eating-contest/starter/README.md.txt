# Pie Eating Contest

Divide a nonnegative whole number of donated pies among four contestants. Each contestant receives only whole pies. Display the starting total, each share and the leftover count.

## Exercise

Complete the exercise above the marked line; keep the supplied output helper.

The supplied printToScreen helper displays text as text, without interpreting HTML.

## Checks

Check totals of 0, 3, 4, 10 and 13 pies. Four times each share plus the leftovers must reconstruct the total, and leftovers must be from 0 through 3. Reject negative, fractional, unsafe or nonnumeric counts.

## Run

Open index.html in a browser. The same HTML, CSS, JavaScript and local D3 files run from the exported project without a network connection. Prompts accept input in browser dialogs; results appear on the page.
