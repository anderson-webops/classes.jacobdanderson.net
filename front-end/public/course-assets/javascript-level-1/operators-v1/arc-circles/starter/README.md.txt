# Circles

Draw a rainbow arc, a full circle and a three-quarter circle with printToScreen(startAngle, endAngle). Convert degrees to radians by multiplying by Math.PI / 180.

## Exercise

Complete the exercise above the marked line; keep the supplied output helper.

Call printToScreen(startAngle, endAngle) with angles in radians.

## Checks

Use -90 to 90 degrees for the rainbow, 0 to 360 for the circle, and 0 to 270 for the three-quarter circle. D3 measures angle zero from the top and positive angles clockwise. The supplied helper retains the original 100/150 inner/outer radii.

## Run

Open index.html in a browser. The same HTML, CSS, JavaScript and local D3 files run from the exported project without a network connection. Prompts accept input in browser dialogs; results appear on the page.
