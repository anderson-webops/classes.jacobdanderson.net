# Tips and Taxes

Calculate the entree cost plus sales tax and tip. Both percentages apply to the original entree cost. Show the final total as currency.

## Exercise

The supplied printToScreen helper displays text as text, without interpreting HTML.

## Checks

For an entree of 20, tax of 10 percent and tip of 15 percent, the total is 25.00. Check a decimal cost, zero percentages, canceled prompts, blank input and an invalid number.

## Run

Open index.html in a browser. The same HTML, CSS, JavaScript and local D3 files run from the exported project without a network connection. Prompts accept input in browser dialogs; results appear on the page.
