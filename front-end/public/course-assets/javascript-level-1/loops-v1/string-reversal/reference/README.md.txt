# String Reversal

Prompt for a word. Print its letters forward with a for loop, then backward with a while loop.

## Checks

Check a one-letter word and a longer word. String indices start at zero; the last valid index is word.length - 1. Check cancellation and empty input. These indexed loops follow JavaScript string code units.

## Run

Open index.html in a browser. The exported HTML, CSS, JavaScript and local D3 files run without a network connection. Prompts accept input in browser dialogs; results appear on the page.
