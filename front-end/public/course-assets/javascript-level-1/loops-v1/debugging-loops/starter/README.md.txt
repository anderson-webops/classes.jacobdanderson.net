# Debugging Loops

Repair the simulation so it runs five races. Each race counts down from ten to one, then advances each of three racers fifty times by a random whole distance from one through ten. Print all three final distances.

This starter is deliberately broken, including a syntax error. Repair one error at a time above the marked line.

## Checks

The starter deliberately has a syntax error plus incorrect countdown, loop and race-counter updates. Repair the first reported error, then trace each loop. Each race prints fifteen messages; each racer's distance lies from 50 through 500.

## Run

Open index.html in a browser. The exported HTML, CSS, JavaScript and local D3 files run without a network connection. Prompts accept input in browser dialogs; results appear on the page.
