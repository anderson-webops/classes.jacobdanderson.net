# For Loops Practice

Use separate for loops to print 1 through 50, 50 down to 1, even numbers 2 through 100, and odd numbers 99 down to 1. Optional challenges: print powers of 3 from 1 through 100, then the sequence 500, 100, 20, 4.

Complete the exercise above the marked line; keep the supplied output helper.

## Checks

The four base groups each contain 50 values. The challenge groups are 1, 3, 9, 27, 81 and 500, 100, 20, 4. Trace initialization, the continuation condition and each update.

## Run

Open index.html in a browser. The exported HTML, CSS, JavaScript and local D3 files run without a network connection. Prompts accept input in browser dialogs; results appear on the page.
