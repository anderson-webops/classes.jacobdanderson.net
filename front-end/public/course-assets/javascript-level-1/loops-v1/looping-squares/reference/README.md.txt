# Looping Squares

Use for loops to draw two red squares and three yellow squares. Then use while loops to draw four blue squares and three purple squares.

## Checks

There are twelve squares, ordered red, yellow, blue and purple. Reset the counter before each while loop. printToScreen(color) draws one complete square and accepts a CSS color.

## Run

Open index.html in a browser. The exported HTML, CSS, JavaScript and local D3 files run without a network connection. Prompts accept input in browser dialogs; results appear on the page.
