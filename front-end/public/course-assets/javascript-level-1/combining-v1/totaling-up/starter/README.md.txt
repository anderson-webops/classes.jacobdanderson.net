# Totaling Up

Use loops to sum 1 through 100, sum the squares of 1 through 100, and find the factorial of a prompted whole number. Initialize or reset the accumulator for each task.

Complete the exercise above the marked line; keep the supplied output helper.

## Checks

The first two results are 5050 and 338350. For factorials, 0 and 1 produce 1; 5 produces 120. The reference accepts whole inputs from 0 through 170 so the result remains finite. Large factorials are floating-point approximations. It reports canceled, blank, fractional, negative and out-of-range input.

## Run

Open index.html in a browser. The project runs offline.
