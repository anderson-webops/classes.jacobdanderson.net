# Coin Machine

Prompt for a whole number of pennies. Use while loops to exchange them for dollars, quarters, dimes and nickels, leaving any remaining pennies.

## Checks

Subtract 100, 25, 10 and 5 in descending order, updating each count. For 187 pennies the result is 1 dollar, 3 quarters, 1 dime, no nickels and 2 pennies. Test 0, 4, 25, 41 and 99. The reference accepts 0 through 1,000,000 pennies to bound the repeated-subtraction work, and reports canceled or invalid input.

## Run

Open index.html in a browser. The project runs offline.
