# FakeTech.io

Create a fictional company employee page using the five supplied biographies and local illustrated portraits in `README.md`. Each employee needs an identity heading, role and complete biography. Keep the same content fields in the same order so readers can compare the cards. The people and company belong to this exercise.

Load Materialize 1.0.0 CSS. A `card-panel` adds padding and elevation; `z-depth-2` sets a shadow and `hoverable` changes it on pointer hover. A `valign-wrapper` uses flex alignment to center children vertically, and `circle` rounds a square portrait. These appearance helpers do not turn a card into a button. Leave these informational cards as ordinary articles.

Use a grid or flex layout to put a portrait beside a biography on large screens. Alternate sides on successive wide cards if desired. At narrow widths stack the portrait and text, keep the complete biography visible, and preserve meaningful reading order. Name each person with a heading; a decorative portrait beside that heading can use an empty alternative.

The starter leaves the five cards unfinished. Check Mark, Molly, Stefan, Sara, and Janet, all five loaded local portraits, complete biographies and roles, circular crops, vertical alignment, and card shadows. Verify wrapping on phones and at 200% zoom. A visual hover effect must not be the only way to discover content. Save a visible edit and export every companion file. This supplemental project practices component styling rather than replacing the core responsive-grid work.

Open index.html in a browser without a server. Keep every companion file when exporting.
