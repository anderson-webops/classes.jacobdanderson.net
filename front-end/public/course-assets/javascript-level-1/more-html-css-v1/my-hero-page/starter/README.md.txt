# My Hero Page

Build a tribute page for a person whose work interests you. Use one `h1`, short factual paragraphs, an image with a useful text alternative, an unordered list of accomplishments, and an ordered list of dated milestones. Use headings in order: `h2` introduces sections below the page's `h1`. An unordered list (`ul`) groups items without a sequence; an ordered list (`ol`) communicates an order, with each item in an `li`.

The project includes the Noto Sans font and its license. Link `noto-sans.css` in the document head, then apply `font-family: "Noto Sans", sans-serif` in `styles.css`. `@font-face` names the included font; `font-family` selects it for content. The included basketball illustration can be replaced by an appropriate local image with permission to use it and an accurate `alt` value. A purely decorative image uses `alt=""`.

Use flexible widths such as `max-width: 50rem; width: 100%`, and `max-width: 100%; height: auto` for the image. Include padding in declared widths with `box-sizing: border-box`. Check that paragraphs, lists, and the image fit a phone-sized viewport and remain readable at 200% zoom. Give links a visible keyboard focus style.

For the supplied LeBron James reference, the list describes selected historical achievements, not a current season's complete totals. Verify dates and factual claims against a primary source, name that source, and distinguish facts from personal opinions. The reference's dated championship milestones are 2012 and 2013 with Miami, 2016 with Cleveland, and 2020 with Los Angeles. A chosen subject can use a different set of verified milestones.

Open `index.html` directly in a browser without a server. Edit `index.html` and `styles.css`, then refresh the browser. The site IDE retains edits and exports all companion files.
