# What Does the _ Say?

Use a `switch` statement with `break` to map lowercase animal names to sounds: dog/woof, cat/meow, cow/moo, bee/buzz, and frog/ribbit. The original reference also gives fox a playful response. Print `huh?` for an unknown animal.

## Checks

Check each listed animal, fox, an unknown animal and a differently capitalized name. Comparisons remain case-sensitive. The reference handles Cancel separately. Every recognized switch case ends with `break`.

## Run

Open index.html in a browser with the exported files together. The project runs offline.
