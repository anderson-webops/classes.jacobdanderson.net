# FizzBuzz

Print the numbers from 1 through 50. Replace multiples of 3 with `Fizz`, multiples of 5 with `Buzz`, and multiples of both with `FizzBuzz`. Check the combined 3-and-5 condition first.

## Checks

Produce exactly 50 lines. Check 1 and 2, 3 (`Fizz`), 5 (`Buzz`), 15, 30 and 45 (`FizzBuzz`), and the final value 50 (`Buzz`).

## Run

Open index.html in a browser with the exported files together. The project runs offline.
