# The Sorting Hat

Prompt for a house and a quality. Use nested conditionals with these exercise rules: Gryffindor/bravery, Slytherin/cunning, Ravenclaw/wisdom, and Hufflepuff/hard work. Print the selected house for a matching pair, a mismatch message for a known house with another quality, and an unknown-house message otherwise.

## Checks

Test all four matching pairs, a mismatch for each house, and an unknown house. Comparisons are case-sensitive. The reference handles Cancel at either prompt before choosing a house.

## Run

Open index.html in a browser with the exported files together. The project runs offline.
