# Debugging a Friend Survey

Open `index.html` with every exported file in place. No server, package installation or network connection is required.

Repair the friend-survey program so four responses appear in one console sentence. Check missing concatenation operators, stored prompt responses, variable declarations and `console.log`. The starter intentionally contains syntax and logic errors; those errors are the exercise.

`prompt()` returns a string or `null` when canceled. The reference handles cancellation before using the responses.

Juni Learning source: [reference](https://codepen.io/junilearning/pen/a16730b9a6d5bba63389d9e3f5614ab9).
