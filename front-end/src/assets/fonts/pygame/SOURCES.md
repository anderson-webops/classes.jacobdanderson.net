# Pygame default font

`freesansbold.ttf` is the unmodified default font from Pygame 2.6.1:
https://github.com/pygame/pygame/blob/b92c0da9d1b5eba6c813138790fc1ab6cea0252c/src_py/freesansbold.ttf

- SHA-256: `bf9251269f11e4b35582a99376096deee3d0c4973a459cbd97b0bebc01f440ad`
- Original bytes: 98600

The font is loaded locally before a PyGame run. The renderer follows
Pygame's default-font size scaling and the font's native line metrics.
Student program text and coordinates are preserved. Native measurement
fixtures use Pygame 2.6.1 and Pygame Zero 1.2.1.
