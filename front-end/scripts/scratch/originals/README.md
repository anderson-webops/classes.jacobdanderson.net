# Original Juni Scratch projects

These are the original published project definitions and media used by the
Scratch Level 1, Level 2 and Game Superstar Bootcamp source courses. Project and
reference roles remain those configured by each course. Existing code can be
partial; a project link does not imply an empty starter or a completed solution.

`catalog.json` retains the author, source URL, source hash and course bindings.
`provenance.json` retains original instructions, credits and publication dates.
`asset-integrity.json` binds every original media file to its byte count and
SHA-256 hash; filenames retain Scratch's original MD5 asset identifiers.

The retained versions were shared and last modified before January 2026.
`license-provenance.json` identifies the pinned official legacy terms and
CC BY-SA 2.0 license applicable to those submissions. Preserve attribution,
license and original credits in redistributed copies. The generated project
adds one collapsed Stage attribution comment, which survives Scratch export,
and a `SOURCE.txt` companion. Every archive retains the byte-identical original
definition as `SOURCE/project.json` and all original media files.

Five project exports use two reviewed SVG compatibility corrections. The rays
backdrop inlines its existing clipping rectangle because the editor sanitizer
removes the SVG `use` element. The watermelon normalizes prefixed SVG element
names before sanitization. Both remain editable vectors with unchanged shapes,
positions and colors. `compatibility.json` pins their original and corrected
hashes and describes each change; affected archives include the same record in
`SOURCE/compatibility.json`. Program blocks and all other media references stay
unchanged. Browser checks compare the corrected editor images to the originals.

The offline generator validates all source and asset hashes before preparing
the public `.sb3` copies. Runtime, extension behavior and task correctness have
separate review evidence. Raw API metadata and temporary project-read tokens
are excluded from this directory. The two optional Scratch 2 typing examples
remain external gameplay resources and are outside this Scratch 3 import set.
