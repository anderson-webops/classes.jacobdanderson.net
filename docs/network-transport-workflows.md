# Optional Network Stack workflow validation

The Unit 1 TCP transfer and UDP extension remain optional and distinct from the
required transport project. Complete readings are bound to the accepted source
revision, with separate learner/reference project keys and preserved earlier
Python attempts. Each consented import contains five role files and its shared
README. Configuration and notebook edits persist through save, reopen and ZIP
export. Runtime success does not complete a notebook.

The browser workflow exercises the actual course cards at mobile and desktop
widths, confirms consent before source fetching, and compares exact and edited
ZIP bytes. The transport native wrapper reconstructs the accepted roles from
their actual browser exports and runs the pinned ordinary-user source verifier.
It retains reports, raw syscall traces and process records under the separate
transport-native output directory. The capstone continues to use its privileged
output directory, and the setup gate keeps its own ordinary-user directory.

The source verifier tests completed, reference and unfinished configurations,
alternate records/datagrams, controlled regressions, fresh-output refusal and
invalid-input refusal. It checks socket/thread cleanup and unchanged source.
Raw traces support application/kernel observations; no packet-boundary,
Internet reachability or notebook-completion claim follows from these checks.
